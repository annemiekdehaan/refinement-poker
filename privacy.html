Privacy and terms

Refinement Poker helps teams estimate work together. No account is required. The app contains no advertising or analytics tracking.

Shared information

Your chosen name, voting status, vote and session details are shared over WebRTC with the facilitator's browser. The facilitator distributes the session state to other participants. Before a reveal, each participant receives only their own vote value and the voting status of others. The facilitator's browser technically processes all votes; this is not a cryptographic voting system.

Storage and connections

The facilitator temporarily stores the session in this tab's sessionStorage to support recovery after a refresh. Names and connection keys are also stored in sessionStorage. There is no central database. Close the tab to clear this storage. CSV exports are saved on your own device. Your browser may cache application files.

Public PeerJS Cloud sets up connections and processes connection identifiers and network information such as IP addresses. Votes travel over WebRTC data connections between browsers. GitHub Pages hosts the website and may process standard access logs. About PeerJS · GitHub privacy statement.

Access and limitations

Anyone with the room code or invitation link can join; there is no login check. Do not include sensitive personal information in names or topics. The facilitator must keep the page open. Leaving ends the session. Corporate networks, VPNs and some NAT configurations can block WebRTC. There is no dedicated TURN relay or availability guarantee. A room allows up to 12 connected participants, including observers.

Microsoft Teams

The app reads your display name from the Teams context to prefill the name field. You can change it. The app does not request access to messages, files, your camera or microphone.
